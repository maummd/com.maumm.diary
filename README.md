# 마음 다이어리 1년 — 음악인지재활 48회기 앱

구의 연세정신건강의학과 사회문화센터 음악인지재활 프로그램용 앱입니다. 진행자는 회기 안내와 게임 화면으로, 회원은 매일 쓰는 마음 다이어리로 사용합니다.

- 패키지 이름: `com.maumm.diary`
- 대상 Android: 8.0 이상 (minSdk 26)
- 서버: 없음 — 다이어리 기록은 **이 휴대폰 안에만** 저장 (로그인 없음)
- 만든 곳: maumm.org (마음엠디와 같은 구조)

## 무엇을 하나요

| 메뉴 | 내용 |

## 폴더

- `web/index.html` — 앱 화면과 동작 전부 (한 파일). 크롬으로 바로 열어 확인할 수 있습니다.
- `android/` — 안드로이드 앱 (화면을 감싸는 WebView + 백업 파일 저장 · 고르기, 노래 링크는 유튜브 · 스포티파이 앱으로 열기)
- `.github/workflows/android.yml` — main에 올릴 때마다 앱 파일 자동 생성

## 앱 파일 받기

1. **Actions** 탭 → 가장 위의 실행(초록 체크)
2. **Artifacts**의 `MaumDiary-테스트용-APK` (바로 설치) 또는 `MaumDiary-출시용-AAB-APK`
3. 서명 키를 등록하면 **Releases → latest**에 휴대폰 바로 받기 링크가 생깁니다.

서명 키: **Settings → Secrets and variables → Actions**에 `KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`

## 데이터와 개인정보

- 저장: WebView 저장소(localStorage), 키 `md1y:cfg` · `md1y:log` · `md1y:pl` · `md1y:best`
- `allowBackup=false` + `data_extraction_rules`로 구글 클라우드 백업 차단 — 휴대폰을 바꿀 때는 **설정 → 백업 파일 만들기**
- 회원 이름 · 진단 등 개인정보는 적지 않도록 안내합니다.
- 노래는 저작권 때문에 가사를 싣지 않고 유튜브 · 스포티파이 검색으로 연결합니다.
